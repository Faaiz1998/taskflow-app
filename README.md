# TaskFlow

A small task-management API. This is the substrate app used across all 5 portfolio
projects (CI/CD, Terraform infra, GitOps/Kubernetes deployment, observability, and
DeployGuard - an ML model that predicts pipeline failure risk).

Deliberately simple on purpose - the point of this app is the infrastructure and
tooling built around it, not the app itself.

## Stack
- FastAPI (API)
- PostgreSQL (database)
- A simple polling worker (background service - the "second service" that makes
  this a genuine multi-service app for Helm/GitOps later)

## Endpoints
- `GET /health` - health check
- `POST /tasks` - create a task (`{"title": "..."}`)
- `GET /tasks` - list all tasks
- `PATCH /tasks/{id}/complete` - mark a task complete

## Run locally

```bash
docker-compose up --build
```

Then:
```bash
curl -X POST localhost:8000/tasks -H "Content-Type: application/json" -d '{"title":"write terraform module"}'
curl localhost:8000/tasks
```

API docs (auto-generated by FastAPI): http://localhost:8000/docs
